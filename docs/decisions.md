## D-002 大文档装载保持同步语义并消除平方级工作
- 日期:2026-08-29
- 决策:`JSONState` 在成功替换或应用状态后递增单调 revision;引用定义缓存必须先比较 revision,仅在版本变化时读取并扫描状态。Markdown 块 token 必须用尾部 `pop/push` 的栈式工作流消费,不得重复移动大数组头部。
- 背景:143K/2100 段文档初始化时,每个内容块都会深拷贝整篇状态,且块解析反复 `shift/unshift`,两处成本都会随块数平方增长。
- 备选与取舍:放弃按顶层块数量缓存,因为同块数引用定义编辑会返回陈旧标签;暂不采用分块/延迟渲染,因为本轮在线性装载语义内已获得约 13 倍改善,无需引入光标、搜索和跨块选择的新状态。
- 影响范围:`packages/muya/src/state/`、`packages/muya/src/inlineRenderer/` 及其自动化测试。
- 状态:生效

## D-003 构建版本默认简体中文
- 日期:2026-09-23
- 关联:R-008
- 决策:默认语言为 `zh-CN`;首次启动不再用系统语言覆盖默认值;已有语言偏好继续生效,英文仍作为缺失翻译的回退。
- 背景:用户明确要求修改源码,让构建版本默认使用中文。
- 取舍:复用现有中文翻译和语言切换机制,不强制覆盖用户已保存的语言。
- 影响范围:默认配置、偏好初始化、主进程与渲染进程语言初始化。
- 状态:生效

## D-004 自定义标题栏横向菜单
- 日期:2026-09-23
- 关联:R-009
- 决策:Windows / Linux 自定义标题栏以八个文字按钮横向显示现有菜单分类;通过 `popupApplicationMenu(position, menuIndex?)` 展开现有 Electron 子菜单,不复制菜单动作或状态。省略索引时保留完整菜单弹出行为。
- 背景:用户要求类似 Typora 的横向菜单。
- 取舍:macOS 与原生标题栏继续使用系统横向菜单;渲染端只维护分类文字和入口,子菜单仍由主进程管理。E2E 对照原生菜单校验分类顺序。
- 状态:生效
